## Solver boundary and next method implementation

`Root/TtbarDileptonFrameReco.cc` contains the existing NuFlows charge/order helpers and a small NW p4 conversion helper. A repository search found no ellipse solver, no neutrino-weighting algorithm implementation, and no API that accepts a supplied pair of b-jet indices and reruns either solver. Therefore `VYPER_EM` and `VYPER_NW` are not fabricated from native-method neutrinos: the required minimum is the validated solver source (or a callable solver library) plus an entry point taking the VyPER ordered b indices, selected leptons, and MET. Once available, `VYPER_EM` is the first controlled rerun to implement.

The native branch inputs are present on the representative MC20a raw slices. The study uses the strict existing population from the presentation summary and does not change its denominator.
